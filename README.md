# 🌿 KochBox | Smart Vending Prototype

**KochBox** is a concept for an affordable, warm, and healthy food vending machine system designed for everyday people. It is targeted at locations such as the Technische Hochschule Ingolstadt (THI), hospitals, and train stations.

👉 **[View the Live Interactive Prototype Here](https://lizomander.github.io/Kochbox-prototype/)**

## 🎯 The Concept
People often need quick, nutritious, and warm meals at odd hours. KochBox solves this by offering a smart, accessible kiosk system. 

Key features include:
* **Reservable Food:** Check stock and reserve meals via the mobile app before walking to the machine.
* **True Accessibility:** A hybrid hardware approach for the physical kiosk, featuring a screen reader mode, tactile D-Pad navigation, and NFC tap-to-dispense for visually and motor-impaired users.
* **Sustainability First:** Options for reusable cups with a deposit (*Pfand*) system alongside single-use items.
* **Multilingual & Cashless:** Built for diverse public spaces with support for multiple languages and modern payment methods (Card, Apple Pay, THI Studentencard).

## 📁 Project Structure
This repository contains the front-end UI prototypes:

* `index.html` - The project landing page and hub.
* `kochbox-mockups.html` - A high-fidelity presentation board showing responsive layouts (Mobile, Tablet, Desktop, Kiosk).
* `app.html` - A fully interactive, clickable prototype of the mobile web app (includes cart logic, allergen filters, and accessibility toggles).
* `kiosk.html` - The inclusive physical vending machine interface concept.

## 🛠️ How to Run Locally
Because this is a static prototype, no build tools or servers are required. 
1. Clone this repository or download the ZIP.
2. Double-click any of the `.html` files to open them directly in your web browser.
